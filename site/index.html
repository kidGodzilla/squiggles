Claude Code agents

Each squiggle owns one part of your work, like the website, the docs or the tests. It shows up without being asked and remembers where it left off. You talk to one of them. The lead hires everyone else.

Apache-2.0. Runs on macOS with Node 20 or newer.

What happens after you install it?

A new room has 1 squiggle in it, the lead.

You say hello

The lead asks your name and what you work on, then turns that into goals.

The lead proposes hires

It suggests one squiggle per area, each with a written charter. You approve or change them.

You merge

The lead reviews each finished branch first. Nothing reaches main until you press Merge.

What keeps them on track?

An agent forgets everything between sessions. Squiggles don't.

They keep a journal

Each one writes down what it did, so tomorrow starts where today stopped.

They share a board

Everyone can see who's doing what, so nothing gets done twice.

They wait instead of watching

A long build doesn't tie anyone up. They get woken when it's done.

You hold the keys

Merging, hiring and anything risky waits for your say-so.

How do I install it?

Paste the prompt into Claude Code, Codex or whatever agent you already use. It clones the repo, checks your Node version, installs the app and opens the room.

Setup prompt

Works in any agent that can run terminal commands.

Set up Squiggles for me. Clone https://github.com/kidGodzilla/squiggles.git to ~/squiggles (pull if it already exists). Check that node --version is 20 or newer; stop and tell me if not. Run bash ~/squiggles/bin/install-app.sh, which adds Squiggles.app and a login item that keeps the server running. Wait until http://127.0.0.1:4327 answers (port is in ~/.squiggles/config.json), then open it. Tell me to say hello to the lead.

By hand

Afterwards, you can open the room from Spotlight.

git clone https://github.com/kidGodzilla/squiggles.git ~/squiggles
cd ~/squiggles
bash bin/install-app.sh
open http://127.0.0.1:4327
